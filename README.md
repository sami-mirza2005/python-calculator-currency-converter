# Python Calculator & Currency Converter

A simple yet practical Python project that combines a basic calculator with a currency converter. This application allows users to perform arithmetic operations and convert between multiple popular currencies through a console-based interface.

## Features

### Calculator
- Addition
- Subtraction
- Multiplication
- Division

### Currency Converter
Supports conversion between:

- BDT (Bangladeshi Taka)
- USD (US Dollar)
- GBP (British Pound Sterling)
- INR (Indian Rupee)
- AED (UAE Dirham)

## Technologies Used

- Python 3
- Conditional Statements (`if-elif-else`)
- Dictionary Data Structure
- User Input Handling
- Arithmetic Operations

## How It Works

### Calculator Mode

The user selects an operation:

```text
1. Addition
2. Subtraction
3. Multiplication
4. Division
```

The program then accepts two numbers and displays the result.

### Currency Converter Mode

The user enters:

- Source Currency
- Target Currency
- Amount

The application first converts the amount into Bangladeshi Taka (BDT) and then converts it into the selected target currency.
